A note on site speed

Not raised in the review, but worth knowing before the meeting.

The cause looks like hosting, not the website

The clearest single measurement: the site's stylesheet is 3.7 KB and takes 5.6 seconds to start arriving. A file that small never touches WordPress, the database or any plugin, so no amount of optimisation, caching or image compression will improve that number.

ResourceSizeTime to first byteTotal
Stylesheet3.7 KB5.57 s5.58 s
Home page136 KB2.31 s13.0 s
What We Do130 KB4.31 s17.5 s
Contact163 KB2.58 s26.8 s
Hero background video11.6 MB5.25 stimed out at 60 s

Total page weight is normal, roughly 1.5 MB across 41 files. The measured transfer rate was about 19 KB per second, which is the real problem.

There is still useful work on our side. The home page plays an 11.6 MB background video, and the media library holds three photographs at 6016 by 4016 pixels, around 4 MB each. That work is worth doing, but it is a small gain on top of a hosting limit, so we should not present it to the committee as a fix for the speed itself.
